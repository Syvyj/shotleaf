Install in a minute

Shotleaf isn’t notarised by Apple yet, so macOS asks once.

  1. Move Shotleaf to Applications and open it.
  2. If macOS can’t check the app, open System Settings › Privacy & Security and click Open Anyway.
  3. When the setup guide asks, allow Screen Recording and Accessibility.
