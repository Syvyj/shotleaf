# Shotleaf 0.5.0 — запис екрана і швидке стискання: план робіт

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Мета:** запис області екрана в MP4 з вікном обрізання і швидке стискання картинок без діалогу, плюс зменшення й пропорції в редакторі і дві дії для Shortcuts.

**Архітектура:** запис — `SCRecordingOutput` (ScreenCaptureKit, macOS 15) у `CaptureKit`. Постобробка (обрізання, «під N МБ», GIF) — AVFoundation + ImageIO в `AppFeature`. Стискання — наявний `SmallFile`, перенесений у фон і викликаний з нових місць. Дії для Shortcuts — App Intents у таргеті `App/`.

**Технології:** Swift 6, macOS 15+, ScreenCaptureKit, AVFoundation, AVKit, ImageIO, App Intents, Swift Testing. Жодних сторонніх пакетів.

**Дизайн:** `docs/superpowers/specs/2026-11-25-0.5.0-recording-compression-design.md` — читати разом із цим планом.

## Глобальні обмеження

- Жодних сторонніх бібліотек (ADR-0071). Лише фреймворки Apple.
- Жодних мережевих запитів. Відео за посиланням (s.syvyj.dev) не ділимося, `server/links` не змінюємо.
- macOS 15+, arm64. Дозвіл лише Screen Recording (уже є).
- Межі для картинок: `[200_000, 500_000, 1_000_000, 8_000_000, 25_000_000]` байтів. Для відео: `[8_000_000, 10_000_000, 25_000_000]`.
- Запис: H.264, MP4, до 30 к/с, рідні пікселі, без звуку, курсор видно, кліки підсвічено.
- Гаряча клавіша запису за замовчуванням ⌘⇧6 (`cmd-shift-6`).
- GIF: 12 к/с, довша сторона ≤ 960 px.
- Звичайні «Копіювати», перетягування, «Поділитися» лишаються повним PNG.
- Стиснута копія в буфері: `public.jpeg` + URL файлу, позначена `ClipboardHistory.ownType`, без PNG/TIFF.
- Тимчасові файли — через `TempFolder`, видаляються лише при наступному запуску.
- Усі нові тексти — EN + UK у `App/Localizable.xcstrings`.
- Тести: `cd ShotleafKit && swift test` (OCR-набір на CI пропускається, як і зараз).
- Коміти лише в локальний `main` / гілку. Пуш на Gitea і GitHub — окремо, з дозволу власника.

## На що дивитися під час рев'ю

1. **Запис на другому дисплеї чи Retina-дисплеї**: записується саме вибраний дисплей і область, у рідних пікселях. Тест у Task 6 (`recordingConfig` для `displayID` і масштабу 2×).
2. **«Стоп» одразу після старту (запис < 0,5 с)**: без падіння. Вікно або не відкривається, або показує коротке відео, «Копіювати» працює. Тест у Task 6.
3. **«Під 8 МБ» неможливе** (довгий запис, навіть 0,25 масштабу не вміщається): помилка зі звуком, а не файл, більший за межу. Тест у Task 7.
4. **Стискання величезного прокрученого знімка** (наприклад, 2000×30000): вікно не підвисає, результат ≤ межі. Тест у Task 1 (виклик поза головним потоком, межа дотримана).
5. **Відкликаний після оновлення дозвіл Screen Recording**: старт запису показує ту саму помилку дозволу, що й знімок, а не чорне відео. Тест у Task 6 (перевірка `CGPreflightScreenCaptureAccess` перед стартом).
