# PLAN.md — APILA

Робочий план. Позначки: `[x]` зроблено · `[ ]` в черзі.
Архітектурні рішення — у `ARCHITECTURE_DECISIONS.md`; тут лише «що робимо і в якому порядку».

## Візія

Архітектура сильна (чисті межі модулів, протоколи в Core, стрімінг), але каркас
випередив продукт. Заморожуємо нові абстракції й доводимо поточний вертикальний
зріз (виділення → ⌘⇧Space → панель → дія → результат) до «користуюсь щодня».
Лише потім — скріншоти/OCR, embedded MLX, дописування тексту.

## Етап 1 — Баги та фундамент

- [x] git + `.gitignore`, початковий коміт
- [x] Тести компілюються під Swift 6 (`InferenceFlowTests` — data race у `eventBus`)
- [x] ⌘C-fallback більше не знищує буфер: відновлюємо всі типи (картинки, файли, rich text) і лише якщо копіювання реально змінило буфер (`SelectedTextReader`)
- [x] Replace / Insert Below повертають попередній вміст буфера після вставки (`ResultInserter`)
- [x] Провайдер перевіряється перед кожним показом панелі: LM Studio, запущений пізніше, підхоплюється без перезапуску; Mock явно позначений у панелі
- [x] Назва провайдера в меню оновлюється
- [x] Хоткей: перевірка кодів повернення (конфлікт видно в меню), `stop()` → `start()` працює, виправлено застарілі коментарі
- [x] Закриття панелі під час генерації не перемикає на екран помилки; дружні тексти помилок `InferenceError`

## Запуск

```bash
./scripts/run.sh   # збірка → підпис «APILA Local Signing» → ~/Applications → старт
```

Підпис локальним сертифікатом (login keychain) робить дозволи macOS сталими між перезбірками.

## Перевірка

```bash
swift build --package-path APILAKit
swift test --package-path APILAKit
xcodebuild -project APILA.xcodeproj -scheme APILA -configuration Debug CODE_SIGNING_ALLOWED=NO build
```
