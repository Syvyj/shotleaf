## 1. Історія git — почистити до першого пушу на GitHub

Публікувати історію як є не можна. Робити на свіжому клоні `main`, одним проходом `git filter-repo`:

- [ ] Справжній IBAN у тесті сніпетів (з'являється в коміті `a23737f`, замінений на фейковий у `94ba0c6`). Замінити через `--replace-text`; у поточному коді вже `UA00`.
- [ ] Старі картинки сайту з особистими даними (`site/assets/*.jpg`, `site/assets/scroll-bar.png`, коміт `4569f99`). Викинути з усієї історії (`--invert-paths`), у поточному дереві їх уже немає.
- [ ] Адреса домашньої мережі в повідомленні коміту злиття `f65620f` (рядок `Reviewed-on: …`). Прибрати через `--replace-message`.
- [ ] Автор `dokboss` у тому ж коміті → `Oleksii Ziuzin <180996981+Syvyj@users.noreply.github.com>` через `--mailmap`.
- [ ] Дрібне: `alpha-1234` у `ClipboardHistoryTests.swift`; адреса сервера коротких посилань у старому мокапі сайту; IP мосту Docker у `server/shots` (за бажання на `172.17.0.1`).
- [ ] Перевірка після чистки: `git log --all -p | grep -E 'UA21|192\.168|homik'` порожньо.
- [ ] Пушити тільки `main`. Гілку `backup/before-author-rewrite` на GitHub не пушити ніколи (там старий автор `Admin` і той самий IBAN).
- [x] `.gitignore`: додати `.env`, `*.pem`, `*.p12`, `*.key`, `*.xcarchive`, `*.dmg`, `*.zip`, `*.safetensors`, `.claude/`.

Що вже перевірено й чисто: жодних токенів, ключів, `.env`, сертифікатів, баз даних, моделей чи `build/` в історії не було; адрес домашнього сервера, ID акаунта Cloudflare, робочої пошти теж немає. Залежності — MIT і Apache-2.0, сумісні з GPL-3.0.
